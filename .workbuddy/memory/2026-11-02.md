## 「稿台 Paperstage」主题补齐（轻拟物 + Win11 Fluent）

**起点**：上一位智能体已完成日夜两套 `ThemeDictionaries`、纸叠层次配色、
框架语义键覆写（Button/TextControl/ComboBox/ListViewItem/TabViewItem）、
8 种指令语义色、列表行模板与流程图代码绘制。`PsSheenTop` 与 `PsShadow`
定义了但 XAML 侧从未用上。

**本次补齐**：
- 组件层：`PsCard`（ContentControl 模板：环境影 + 关键影 + 卡面渐变 +
  1px 发丝边 + 顶缘 `PsSheenLine` 高光）、`PsWell`（顶部内阴影的凹陷字段区）、
  `PsIconButton`（无边框图标钮，四态手写模板）、`PsSectionTitle`/`PsCaption`。
- 主题键：`AccentButton*`（主操作实底朱砂）、`ToolTip*`、`ContentDialog*`、
  `ScrollBar*`、`MenuFlyout*`、`AppBarSeparatorForeground`、
  `TextControlSelectionHighlightColor`；新增令牌 `PsHoverFill`/`PsShadowAmbient`/
  `PsWellShade`/`PsSheenLine`/`PsOnAccent`/`PsScrim`，删掉未使用的 `PsSheenTop`。
- 状态语义：悬停改中性暖灰、选中保持朱砂淡染（原先两者同色，划过与选中分不清）；
  隐藏框架在选中行左侧另画的那条强调色竖条（与主题「书脊」打架）；
  选中行文字回到墨色（cinnabar-on-wash 在深色只有 4.06:1）。
- 标题栏：`AppWindow.TitleBar` 配色随主题（案垫底 + 墨色字）。坑：
  ① 主题字典里的 `Color` 键运行时查不到，只能取画刷再读 `.Color`（`Theme.Swatch`）；
  ② `ButtonBackgroundColor` 设成全透明会被 DWM 涂成纯黑。
- 可访问性：`PsInkTertiary` 日夜都提到 ≥4.5:1；`PsKindGoto/Clear` 压深；
  `PsThread` 提到 3:1；`PsCinnabarHover`(日) 与 `PsCinnabarPressed`(夜) 微调，
  保证强调按钮 hover/pressed 时纸色字仍 ≥4.5。
- 布局修缺：节点卡三个文字按钮在 232 宽被裁切 → 主操作留文字、删除/设入口收成
  图标钮；「类型」下拉与动作按钮改两行（原先靠横向滚动勉强看全）。
- `check_theme.py` 扩成「键对应 + 引用存在 + WCAG 对比度」三检，失败退出码 1。
- `shot.ps1` 改为 DPI 感知 + 可点/可悬停/可 Tab，用于验证交互态。
- 顺手删掉 `MainWindow` 里每次启动往源码树写 `diag.txt` 的调试残留。

**验证**：`dotnet build`（0 警告 0 错误）、`dotnet test`（39 通过）、
`python check_theme.py`（通过）、浅深两套截图逐页看过（结构/编排/流程图），
并实测 hover（强调色 #B0432E→#BE4C35、图标钮浮出中性底）、键盘焦点（纸色内圈）、
新增节点（状态栏 5 节点 / 撤销 1）。
