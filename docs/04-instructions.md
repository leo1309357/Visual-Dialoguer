# 04 · 指令类型与字段

CDLG 共 **8 种指令**,类型顺序固定(与 `cdlg::InstructionKind` 一致,编辑器的类型下拉框也按这个顺序排):

| # | 关键字 | 显示名 | 徽章 | 语法 |
| --- | --- | --- | --- | --- |
| 0 | `speaker` | 说话人 speaker | 说 | `speaker <name>` |
| 1 | `line` | 台词 line | 词 | `line <text>` |
| 2 | `choice` | 选项 choice | 选 | `choice <label> -> <node>` |
| 3 | `goto` | 跳转 goto | 跳 | `goto <node>` |
| 4 | `set` | 置标志 set | 置 | `set <flag> <value>` |
| 5 | `clear` | 清标志 clear | 清 | `clear <flag>` |
| 6 | `emit` | 发信号 emit | 信 | `emit <signal> [payload]` |
| 7 | `end` | 结束 end | 止 | `end` |

徽章是界面(指令列表、流程图)使用的单字语义标记。

---

## 4.1 speaker — 说话人

设置当前说话人,影响后续 `line` 的归属。

```
speaker 旅店老板
speaker Narrator
```

| 字段 | 名称 | 说明 |
| --- | --- | --- |
| `Speaker` | 说话人 | 必填;转义字段,支持 `\n` 等 |

**校验**:`speaker` 指令的说话人为空 → `节点 'x' 的 speaker 指令缺少说话人`。

## 4.2 line — 台词

输出一句台词。

```
line 欢迎来到云雾镇,旅行者。
line 你可以选择:\n1. 打听\n2. 离开
```

| 字段 | 名称 | 说明 |
| --- | --- | --- |
| `Text` | 文本 | 必填;转义字段 |

**校验**:`line` 指令的文本为空 → `节点 'x' 的 line 指令缺少台词文本`。

## 4.3 choice — 选项

给玩家一个分支选项,选中后跳转到目标节点。

```
choice 打听传闻 -> rumor
choice 直接出发 | leave        ← 解析也接受 | 分隔
```

| 字段 | 名称 | 说明 |
| --- | --- | --- |
| `Text` | 选项文本 | 必填;转义字段;**不能包含 `->` 或 `|`** |
| `TargetNode` | 目标节点 | 必填;**必须指向存在的节点** |

**校验**:
- 选项文本为空 → `节点 'x' 的 choice 选项标签不能为空`;
- 标签包含 `->` 或 `|` → `节点 'x' 的 choice 标签不能包含分隔符 '->' 或 '|'`(保存后读不回);
- 目标节点为空 → `节点 'x' 的指令缺少目标节点`;
- 目标节点不存在 → `节点 'x' 引用了不存在的节点 'y'`。

## 4.4 goto — 跳转

无条件跳转到目标节点,当前节点到此中断。

```
goto leave
```

| 字段 | 名称 | 说明 |
| --- | --- | --- |
| `TargetNode` | 目标节点 | 必填;**必须指向存在的节点** |

**校验**:同 `choice` 的目标节点规则(缺目标 / 目标不存在都报错)。

## 4.5 set — 置标志

把对话标志(flag)设为一个值。常用于记录剧情状态。

```
set rumor_heard yes
set gold 100
```

| 字段 | 名称 | 说明 |
| --- | --- | --- |
| `FlagKey` | 标志键 | 必填;标识符:非空白、不含空白字符、不能以 `#` 开头 |
| `FlagValue` | 标志值 | 必填;转义字段 |

**校验**:
- 键或值为空 → `节点 'x' 的 set 指令需要 <标志> <值>`;
- 键不合法(见下)→ `节点 'x' 的标志名 '...' 不能包含空白字符` / `不能以 '#' 开头`。

## 4.6 clear — 清标志

清除一个对话标志。

```
clear rumor_heard
```

| 字段 | 名称 | 说明 |
| --- | --- | --- |
| `FlagKey` | 标志键 | 必填;标识符规则同 `set` |

**校验**:
- 标志名为空 → `节点 'x' 的 clear 指令缺少标志名`;
- 键不合法 → 同上。

## 4.7 emit — 发信号

发出一个游戏信号,可带可选载荷(payload)。用于向游戏运行时广播事件(播放音效、触发演出等),具体语义由 Session 运行时决定。

```
emit sfx_door
emit quest_started 古堡之谜
```

| 字段 | 名称 | 说明 |
| --- | --- | --- |
| `SignalId` | 信号 ID | 必填;标识符:非空白、不含空白字符、不能以 `#` 开头 |
| `SignalPayload` | 信号载荷 | 可选;为空时序列化不输出;转义字段 |

**校验**:
- 信号 id 为空 → `节点 'x' 的 emit 指令缺少信号 id`;
- 信号 id 不合法 → `节点 'x' 的信号 id '...' 不能包含空白字符` 等。

## 4.8 end — 结束

结束当前节点块(对话到此结束)。**注意**:节点块 `end` 缩进 2,指令 `end` 缩进 4,二者是不同层级的东西(见 [03 · 格式与语法](03-format.md))。

```
end
```

无字段,无专项校验。

---

## 4.9 标识符规则(flag / signal / 节点 id 通用)

`set` / `clear` 的标志键、`emit` 的信号 id、节点 id、目标节点引用都按"按词切分的标识符"处理,共享同一套合法性规则:

1. 不能为空串(各字段的必填检查单独负责报错);
2. 不能**只含空白字符** → `... 只含空白字符`;
3. 不能以 `#` 开头(会被解析器当注释吃掉)→ `... 不能以 '#' 开头(会被当作注释)`;
4. 不能**包含任何空白字符**(空格 / Tab / 换行)→ `... 不能包含空白字符`。

> 直观理解:这类字段在行内是"一个词",含空白就切碎了;以 `#` 开头则整行变成注释。**`speaker` 的人名、`line` 的台词、`choice` 的标签、`set` 的值、`emit` 的载荷不受此限**(它们可以含空格,用转义处理特殊字符)。

## 4.10 切换指令类型时的字段清理

在编辑器里把一条指令**改成另一种类型**时,原来类型的字段会被清空,避免"存出去一半旧一半新":

| 切换后类型 | 保留的字段 | 被清空的字段 |
| --- | --- | --- |
| `speaker` | `Speaker` | 其余全部 |
| `line` | `Text` | 其余全部 |
| `choice` | `Text`、`TargetNode` | 其余全部 |
| `goto` | `TargetNode` | 其余全部 |
| `set` | `FlagKey`、`FlagValue` | 其余全部 |
| `clear` | `FlagKey` | 其余全部 |
| `emit` | `SignalId`、`SignalPayload` | 其余全部 |
| `end` | 无 | 其余全部 |
