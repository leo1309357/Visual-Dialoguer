# 02 · 快速开始

## 1. 准备一个 `.cdlg` 文件

用任何文本编辑器创建 `hello.cdlg`,内容如下(缩进 2 或 4 空格均可,但**层级**必须正确,见 [03 · 格式与语法](03-format.md)):

```
dialogue opening
  entry start
  node start
    speaker 旅店老板
    line 欢迎来到云雾镇,旅行者。
    choice 打听传闻 -> rumor
    choice 直接出发 -> leave
  end
  node rumor
    line 据说北边的古堡最近闹鬼。
    goto leave
  end
  node leave
    line 一路小心。
    end
end
```

保存文件(UTF-8 编码即可;编辑器对 BOM、CRLF 都宽容)。

## 2. 用 VisualDialoguer 打开

启动编辑器,点工具栏 **打开** 按钮(或 `Ctrl+O`),选择 `hello.cdlg`。

- 左侧**节点栏**出现三个节点:`start`、`rumor`、`leave`;
- 左侧第一个节点自动被选中,中栏显示它的指令列表;
- 状态栏显示:节点数、指令数、撤销 / 重做深度。

## 3. 浏览与编辑

- 点中栏任意指令,右侧**属性面板**显示该指令的字段,直接改;
- 点左侧节点栏下方的 **＋** 新建节点;点 **★** 把选中节点设为入口;
- 在节点内选中指令后,可用中栏的 **上移 / 下移** 调整顺序,或 **删除**;
- 所有改动实时反映到状态栏的未保存标记(标题前的 `*`)。

## 4. 校验

按 `F5`(或工具栏 **校验** 按钮)运行结构校验:

- 校验通过:状态栏显示"校验通过:没有发现问题。";
- 发现问题:弹出校验报告,逐条列出(如"入口节点 'x' 不存在")。

校验规则完整清单见 [04 · 指令类型与字段](04-instructions.md) 与 [05 · 节点与入口](05-nodes.md)。

## 5. 看流程图

按 `Ctrl+F`(或工具栏 **流程图** 按钮)打开流程图覆盖层:

- 每个节点是一张索引卡,卡片左侧的**书脊**颜色取自该节点第一条指令的语义色;
- 入口节点卡片的书脊与标题用签名色,并带 `★` 前缀;
- `choice` / `goto` 指令画成卡片之间的**牵线**,带箭头;`choice` 的选项文本做成压在连线中点的小纸片;
- 点某张卡片,覆盖层关闭,工作台选中该节点。

## 6. 保存

按 `Ctrl+S` 保存。若文件还没存过盘,会弹出保存对话框,默认文件名是脚本 id + `.cdlg`。

编辑器保存时输出 **UTF-8 无 BOM、LF 换行**的文本——Eraphanis 的 `libs/cdlg` 解析器可以直接加载。

## 7. 快捷键速查

| 快捷键 | 动作 |
| --- | --- |
| `Ctrl+N` | 新建空白脚本 |
| `Ctrl+O` | 打开 `.cdlg` / `.txt` 文件 |
| `Ctrl+S` | 保存 |
| `Ctrl+Shift+S` | 另存为 |
| `F5` | 校验脚本 |
| `Ctrl+F` | 切换流程图覆盖层 |
| `Ctrl+Z` | 撤销 |
| `Ctrl+Y` | 重做 |
