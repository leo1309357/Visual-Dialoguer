# 06 · 编辑器操作指南

VisualDialoguer 是 CDLG 的可视化编辑器(WinUI 3 桌面程序)。本章介绍完整界面与操作。

## 6.1 界面总览

```
┌─────────────────────────────────────────────────────────────────────┐
│ 标题栏(VisaulDialoguer - 文件名)                                      │
├─────────────────────────────────────────────────────────────────────┤
│ [新建][打开][保存][另存为] | [校验 F5] [撤销][重做]      [流程图][深浅色] │  ← 工具栏
├──────────────────┬──────────────────────────┬───────────────────────┤
│ 节点栏            │ 指令流                     │ 属性面板                │
│  搜索框           │ 类型下拉 + 搜索 + 筛选chips │ (InstructionEditorPanel)│
│  节点列表         │ 指令列表(徽章+摘要)         │ 字段编辑区              │
│  [＋][删除][★]   │ [新增][删除][上移][下移]    │                        │
├──────────────────┴──────────────────────────┴───────────────────────┤
│ 状态栏:提示文本 · 节点 N · 指令 M · 撤销 X · 重做 Y                     │
└─────────────────────────────────────────────────────────────────────┘
```

- **工具栏**:文件操作、校验、撤销重做在左;流程图与深浅色切换在右;
- **工作台**:三栏——左**节点栏**、中**指令流**、右**属性面板**;
- **状态栏**:左是提示文本(最近一次操作结果),右是统计(节点数、指令数、撤销/重做深度);
- **标题栏**:显示文件名;有未保存改动时,标题前有 `*`。

## 6.2 文件操作

| 按钮 | 快捷键 | 动作 |
| --- | --- | --- |
| 新建 | `Ctrl+N` | 新建空白脚本(id 为 `untitled`) |
| 打开 | `Ctrl+O` | 打开 `.cdlg` / `.txt` 文件 |
| 保存 | `Ctrl+S` | 保存到当前路径;没存过盘则弹出保存对话框(默认文件名:脚本 id + `.cdlg`) |
| 另存为 | `Ctrl+Shift+S` | 总是弹出保存对话框 |

行为细节:

- **打开**时,编辑器解析文件;若文件里没有 `dialogue` 块,状态栏提示"这个文件里没有 dialogue 块。";
- 若解析出问题,状态栏提示"已载入,但解析报了 N 个问题(按 F5 看详情)。";
- **新建 / 打开前**若有未保存改动,会弹确认对话框(取消则中止操作);
- **关闭窗口**时若有未保存改动,同样先确认;
- 保存写盘成功后才更新"已保存"基准与路径,状态栏显示"已保存 <路径>"。

## 6.3 节点栏(左栏)

- **搜索框**:按节点 id 过滤列表(不区分大小写);
- **节点列表**:每行显示节点 id;入口节点带 `★`;右侧显示指令条数;
- 按钮:
  - **＋ 新增**:自动命名 `node1`、`node2`…(不重复),新节点自动选中;
  - **删除**:删除选中节点;若它是入口,入口定义一并清空;
  - **★ 设为入口**:把选中节点设为入口节点。

## 6.4 指令流(中栏)

- **类型下拉(KindPicker)**:选类型后点新增,插入该类型指令;顺序固定为 8 种指令类型;
- **搜索框**:按指令摘要、说话人、目标节点过滤;
- **筛选 chips(FilterBar)**:`全部` + 8 个单字徽章(`说` `词` `选` `跳` `置` `清` `信` `止`),点一个只显示该类型;
- **指令列表**:每行 = 徽章 + 类型名 + 摘要(说话人/文本/目标);
- 按钮:**新增**(按下拉类型)、**删除**、**上移**、**下移**;
- 选中指令后,右侧属性面板显示其字段。

> 筛选 / 搜索时列表只显示子集,但**选中与操作始终作用到真实指令**:列表行保存了真实下标,增删移动不会选错对象。

## 6.5 属性面板(右栏)

`InstructionEditorPanel` 按指令类型显示对应字段(顺序与 `InstKindInfo.Fields` 一致):

| 指令 | 字段 |
| --- | --- |
| `speaker` | 说话人 |
| `line` | 文本 |
| `choice` | 选项文本、目标节点 |
| `goto` | 目标节点 |
| `set` | 标志键、标志值 |
| `clear` | 标志键 |
| `emit` | 信号 ID、信号载荷 |
| `end` | (无字段) |

- 字段**就地编辑**,改完即生效(标题栏 `*` 出现);
- 属性编辑采用**焦点式撤销**:进入字段时取快照,失焦且有改动时压入撤销栈——不会出现逐键撤销把撤销栈塞满的情况;
- 切换指令类型时,无关字段被清空(见 [04 · 4.10](04-instructions.md#410--切换指令类型时的字段清理))。

## 6.6 校验(F5)

按 `F5` 或点工具栏 **校验**:

- 通过:状态栏"校验通过:没有发现问题。";
- 有问题:弹出校验报告,逐条列出(如 `节点 'x' 引用了不存在的节点 'y'`),状态栏同时显示摘要。

校验规则清单见 [04](04-instructions.md) 与 [05](05-nodes.md)。**解析错误**(打开文件时报的)与**结构校验错误**(F5 报的)是两回事:前者是文件读不进,后者是结构不合法。

## 6.7 撤销 / 重做

- `Ctrl+Z` 撤销,`Ctrl+Y` 重做(工具栏也有按钮);
- 实现为**整份快照**,容量 **50 层**(超出丢最旧的);
- 撤销栈 / 重做栈深度实时显示在状态栏;
- 属性面板的**逐键输入不入栈**(见 6.5);
- 新建 / 载入会清空历史。

## 6.8 剪贴板:指令与节点两级

| 动作 | 说明 |
| --- | --- |
| 复制指令 | 复制选中指令的深拷贝 |
| 剪切指令 | 复制 + 删除 |
| 粘贴指令 | 追加到当前节点末尾并选中 |
| 复制节点 | 复制选中节点(含全部指令) |
| 剪切节点 | 复制 + 删除 |
| 粘贴节点 | 插入副本,id 自动改为 `原id-copy`(冲突则 `-copy-2`…) |

节点剪贴板与指令剪贴板**相互独立**(两级剪贴板)。粘贴节点时 `goto`/`choice` 的引用**不重定向**。

## 6.9 流程图(Ctrl+F)

按 `Ctrl+F` 或点工具栏 **流程图** 打开覆盖层:

- 节点按**顺序排成 3 列规则网格**(每列宽 = 卡宽 + 间距,每行高 = 卡高 + 间距),自上而下、从左到右;
- 每张卡:柔影 → 卡面 → **书脊**(颜色取节点第一条指令的语义色;入口节点用签名色)→ 标题与指令条数;
- 入口节点标题带 `★`,文字用签名色;
- `choice` / `goto` 画成**牵线**:源卡右侧中点 → 目标卡左侧中点,带三角箭头;`choice` 的标签是压在连线中点的小纸片,`goto` 标 `goto`;
- 目标节点不存在的连线**画不出来**(校验会报);
- **点任意卡片**:覆盖层关闭,工作台选中该节点;
- 再次按 `Ctrl+F`(或点右上角关闭按钮)关闭覆盖层。

流程图是**算出来的,不是拖出来的**——脚本一改,图就重画,不会出现"图和脚本对不上"。

## 6.10 深浅色主题

工具栏最右侧 **切换深浅色** 按钮:

- 在浅色 / 深色之间切换,即时生效;
- 标题栏、工作台、流程图全部跟随(流程图是代码逐笔绘制,主题切换时会重画);
- 主题来自独立的 **Loma** 主题库(`Loma.Theme`,WinUI 类库)。

## 6.12 文件格式约定

- 保存:UTF-8 **无 BOM**、LF 换行;
- 打开兼容:`.cdlg` 与 `.txt`;BOM / CRLF 都能吃;
- 默认扩展名 `.cdlg`。
