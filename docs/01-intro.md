# 01 · 简介

## CDLG 是什么

**CDLG**(Conversations Dialogue Script)是 Eraphanis 工程里驱动游戏对话的脚本语言。对话以**脚本块**的形式写在 `.cdlg` 文本文件里,由 `libs/cdlg` 解析器读取,交给 Session 运行时驱动 NPC 对话、分支选项与剧情跳转。

一个对话脚本由三样东西组成:

1. **脚本块(`dialogue`)**——一段完整对话的容器,有自己的 id;
2. **节点(`node`)**——一串按顺序执行的指令,是对话的"场景单元";
3. **指令(instruction)**——最小动作,例如"某人说了一句话"、"给出一个选项"、"跳去某个节点"。

脚本内所有跳转都以**节点 id** 为目标。结构是树状的,数据流是跳转驱动的。

## VisualDialoguer 的角色

**VisualDialoguer** 是 CDLG 的可视化编辑器(Windows 桌面程序,C# / WinUI 3):

- 把 `.cdlg` 文本解析成结构化的节点 / 指令模型,以**三栏工作台**(节点 / 指令 / 属性)编辑;
- 提供**流程图覆盖层**,把节点与 `goto` / `choice` 连线画成规则网格;
- 提供**校验(F5)**与解析报告,在保存前拦住结构错误;
- 写出的文件与 `libs/cdlg` 解析器、Session 运行时**直接兼容**。

```
.cdlg 文本 ──解析──▶ 内存模型 ──编辑──▶ 内存模型 ──序列化──▶ .cdlg 文本
                        ▲                                    │
                        └────────── 校验 / 流程图 ◀───────────┘
```

## 设计目标

- **人类可读**:CDLG 是行式文本,缩进表达层级,`#` 写注释,任何文本编辑器都能改;
- **机器可靠**:三级缩进规则严格,序列化输出与解析器约定完全一致,写出的文件必然能读回;
- **可脚本化**:整个对话是纯文本,可以放进版本控制、做 diff、参与自动化流程;
- **编辑器友好**:结构规整,适合可视化的节点—连线呈现。

## 与 Eraphanis 工程的关系

- 语法与缩进规范与 `libs/cdlg` 解析器(**Parser.cpp**)保持一致;
- 编辑器写出的转义、缩进、选项分隔符(归一化为 `->`)是解析器的**合法输入**;
- 结构校验规则与 `libs/cdlg/src/Parser.cpp` 的检查一致(入口存在、id 不重复、节点非空壳、跳转目标存在)。

> VisualDialoguer 项目本身已从 Eraphanis 仓库独立出来,不共享任何构建;两者只通过 `.cdlg` 文本这一种格式交互。

## 支持范围

- 编辑器只**编辑每个文件里的首个 `dialogue` 块**;文件里其余块会被原样保留,保存时写回(详见 [08 · 常见问题](08-faq.md));
- 流程图是**按节点顺序计算的规则网格**,不支持手动拖动布局;
- 文本格式:序列化输出 **UTF-8 无 BOM、LF 换行**;解析时 BOM、CRLF、`\r` 都能容忍。
