# 08 · 常见问题

## 兼容性

### 编辑器写出的文件,游戏引擎能直接加载吗?

能。序列化严格对齐 `libs/cdlg` 解析器约定:

- 缩进:`dialogue` / 顶层 `end` = 0;`entry` / `node` / 节点块 `end` = 2;指令 = 4;
- 选项分隔符归一化为 ` -> `;
- 转义序列 `\n \t \r \\ \"` 双向往返,未知 `\x` 保留反斜杠;
- 编码 UTF-8 无 BOM + LF。

### 打开兼容哪些格式?

`.cdlg` 与 `.txt`。解析宽容:BOM、`#` 注释、空行、CRLF 都能吃;Tab 按加权宽度折算进缩进层级(1 Tab = 2 空格)。

### 结构校验与引擎一致吗?

一致。校验规则与 `libs/cdlg/src/Parser.cpp` 的检查对齐:入口存在、节点 id 唯一、节点非空壳、goto/choice 目标存在;编辑器还额外提示各指令的必填字段。

## 已知限制

### 为什么编辑器只编辑文件里的第一个 dialogue 块?

设计如此。解析时所有块都进模型,但界面只暴露**首个块**;其余块在保存时**原样写回**(不经过编辑器的序列化逻辑)。界面目前不提供切换块的入口。

> 需要编辑多段对话时,把目标块放在文件最前面。

### 流程图能手动拖动布局吗?

不能。流程图是**按节点顺序算出来的规则网格**(3 列),脚本一改图就重画,保证图和脚本永远一致。需要手动布局请改脚本顺序。

### choice 标签里能写 "->" 或 "|" 吗?

不能。`->` 与 `|` 都是解析器的选项分隔符,标签里含它们会切不出目标节点。校验器会拦下:`choice 标签不能包含分隔符 '->' 或 '|'`。

### 节点 id / 标志名 / 信号 id 能含空格或以 # 开头吗?

不能。它们是按词切分的标识符:含空白会被切碎,以 `#` 开头会被当注释。校验器会拦下。

### 为什么不能撤销到"没改之前"的每一步?

撤销栈容量 50 层(超出丢最旧),且属性面板**逐键输入不入栈**(取快照、失焦才入栈),避免撤销栈被单字符记录淹没。这属于预期行为。

## 排错

### 打开文件提示"这个文件里没有 dialogue 块。"

文件里没有合法的 `dialogue <id>` 行。检查:首行是否为 `dialogue <id>`(缩进 0),或文件是否为空/全注释。

### 打开文件提示"已载入,但解析报了 N 个问题"

文件读进来了,但有解析问题(如缩进层级错、命令拼错、缺参数)。按 `F5` 查看逐行详情,每条都带行号。

### F5 校验报"入口节点 'x' 不存在"

`entry x` 指向的节点不存在。可能:节点被删了,或 id 拼写不一致(大小写敏感)。在节点栏加回该节点,或把 `entry` 改指向存在的节点。

### F5 校验报"节点 'x' 引用了不存在的节点 'y'"

某个 `goto` / `choice` 指向不存在的节点。删除该指令,或补建节点 `y`。注意:流程图里这种连线**画不出来**,可借此定位。

### 校验报"节点 'x' 没有任何指令"

节点是空壳。给它加至少一条指令,或删除该节点。

### 保存后文件打不开 / 引擎报错

- 确认没有把非法内容写进标识符字段(含空白 / `#` 开头 / `choice` 标签含分隔符)——这些在保存前会被 F5 拦下;
- 确认文件编码为 UTF-8(无 BOM 即可);
- 确认缩进层级没有错位。

### 撤销栈深度总是 0?

新建 / 载入会清空历史;若刚打开文件还没做过改动,撤销栈自然是空的。

## 开发者

### 文档如何生成静态网站?

```
python tools/build_docs.py
```

从 `docs/*.md` 生成单文件自包含 HTML(内嵌样式与导航),浏览器直接打开,或部署到任意静态托管。
